# 电梯维保单位信用评分工具（广西通用）

一套开箱即用的电梯维保单位信用记分与统计工具。用浏览器打开就能录、能查、能导出，
把过去手工填表、逐条汇总的做法换成一个多人共用的小网站。

**本仓库不含任何单位与个人数据**，下载后请先导入你本地的维保单位名单。

- **零依赖**：只要装了 Node.js（18 及以上）就能跑，不需要 npm install，不需要联网
- **自带单位导入**：下载模板 → 填写名单 → 一键导入（Excel / CSV 都支持）
- **单机即可运行**：数据全在一个 `db.json` 文件里，复制走就是备份
- **默认只读**：拿到链接的人只能看和导出；录入、删除、修改、导入都要密钥
- **手机也能用**：页面是移动端优先设计的，现场检查时可直接录入

---

## 一、快速开始

```bash
# 1. 确认 Node.js 已安装（18 及以上）
node -v

# 2. 启动
node server.js

# 3. 打开浏览器
#    http://localhost:3000
```

Windows 用户也可以直接双击 `启动.bat`。

第一次打开时单位库是空的，页面会自动停在「**单位库**」页，按下面的步骤导入名单即可开始记分。

---

## 二、导入维保单位（第一次使用必做）

1. 在「**单位库**」页点 **⬇ 导入模板(Excel)** 或 **⬇ 导入模板(CSV)**，把模板下载下来；
2. 按模板列填写单位信息，**「单位名称」列必填**，其余列可留空；
3. 保存文件，回到页面点 **📥 选择文件导入（Excel / CSV）**，选中刚才的文件；
4. 导入完成后会显示「新增 X 家、更新 X 家」，下方列表立即刷新。

### 模板列说明

| 列名 | 必填 | 说明 |
|---|---|---|
| 单位名称 | ✅ | 同名视为同一家单位，重复导入会按表内信息更新，不会重复新增 |
| 辖区 | | 办公点所在城区 / 县，如「青秀」「叠彩」 |
| 许可证号 | | 安装改造维修许可证编号 |
| 许可级别 | | A1 / A2 / B / 不分级 等 |
| 许可范围 | | 安装、改造、维修等 |
| 办公地点 | | 详细地址，页面上一键导航用 |
| 联系人 | | |
| 联系电话 | | 页面上可一键拨号 |
| 备注 | | 如「本市取证」「区内维保备案」 |

### 导入规则

- **表头只要含义对得上就行**：写成「维保单位名称」「办公点辖区」「电话」也认，顺序可以不一样，多余列自动忽略；
- **首次导入（单位库为空）不需要密钥**；库里已经有数据时，导入需要验证身份，防止被误改；
- 支持 **Excel(.xlsx)** 与 **CSV**；CSV 若为 GBK 编码（Excel 另存常见）会自动识别，不会乱码；
- 两种模式：**追加 / 更新**（推荐，只加新的、更新已有的）、**清空后重建**（会连同记分记录一起清空，慎用）；
- 单位名称为空的行会自动跳过。

导入后如需零星调整，可在「单位库」列表里直接删除单位（已有记分记录的单位不允许删除），
联系人 / 电话 / 地址也可以在「计分汇总」页点开单位后修改。

## 三、改配置（config.js）

```js
module.exports = {
  siteName: '电梯维保单位信用评分',   // 页面顶部标题
  siteSub:  '记分制 100 − 扣分 + 加分',
  keyQuestion: '请输入管理密钥',      // 页面上显示的提问
  keyAnswer:   'admin',              // ★ 首次使用请务必改成自己的
  keyWrongMsg: '密钥错误，请联系系统管理员',
  port: 3000,                        // 端口
  corsOrigin: '*',                   // 跨域白名单，正式部署建议改成具体域名
};
```

改完保存，**重启服务**生效。密钥答案只保存在服务端，网页源码里看不到。

> 评分标准（38 条）放在 `db.json` 的 `standards` 里，各地如评价办法不同，直接改这个文件即可；
> 页面上的条款、分值、否决项判定都从这里读。

## 四、功能一览

### 记分录入
- 选单位、日期、检查类型、条款、分值、事由、录入人
- **高频扣分项快捷卡片**：按实际使用频率自动排出最常用的 8 个条款，点一下自动填好
- 选到否决项条款自动锁定 50 分并判 D 级
- 保存后自动重算得分、等级、排名

### 计分汇总
- 所有单位的扣分、加分、最终得分、等级一览
- 点「单位 / 辖区 / 最终」表头可排序，默认最低分在最前
- 按等级筛选、按关键词搜索、点开看记分明细
- 按等级自动生成下一年度监督检查次数建议

### 评分标准
- 38 条评分标准（扣分 / 否决项 / 加分），标注每条被实际使用的情况
- 可按编号或涉及单位数排序

### 季度通报
- 按季度生成通报内容：单位、违法违规事实、本季扣分
- 对应评价办法要求的通报要素

### 导出
- 记分汇总表（汇总 + 明细两个工作表）
- 季度通报（全年 4 个季度分表）
- 前三季度记分情况表
- 年度监督检查计划表
- 也可导出 CSV

### 权限设计
- 默认只读：查看、导出不受限制
- 录入 / 导入 / 修改需密钥，密钥只在服务端比对
- **申请制**：只读状态下任何录入、修改都只生成申请，由验证过身份的人确认后才正式生效
- **编辑 / 删除已录记分**：需先「验证身份」；可改日期、条款、分值、事由、录入人，单位不可改
- **只读脱敏**：季度通报的「违法违规事实」在只读状态下不显示，导出时同样隐去

## 五、计分规则

- 得分 = 100 − 扣分 + 加分
- 加分封顶：管理创新 5 分；智慧管理、保险服务、公益服务各 10 分
- 总分不封顶
- **否决项一次扣 50 分**，触发即判 **D 级**；D 级不显示具体得分

> 评分标准取自广西区级电梯维保单位信用评价相关文件，具体以本地正式发布的监管文件为准；
> 如有调整，改 `db.json` 的 `standards` 与 `server.js` 顶部的对应常量。

## 六、目录结构

| 文件 | 作用 |
|---|---|
| `server.js` | 后端服务，接口、导入、导出 |
| `index.html` | 网页界面（样式和脚本都在里面） |
| `import.js` | 单位信息导入解析（CSV / xlsx，零依赖自实现） |
| `xlsx.js` | 极简 Excel(xlsx) 生成模块 |
| `db.json` | 全部数据（单位、评分标准、记分、待确认申请） |
| `config.js` | 站点名称、密钥、端口等配置 |
| `启动.bat` | Windows 双击启动 |
| `使用说明.md` | 面向使用者的操作说明 |

**备份**：复制 `db.json` 即可。
**迁移**：整个文件夹拷给对方，让对方用自己的 `db.json` 覆盖。

## 七、常见问题

**Q：打开是白屏？**
A：确认 Node.js ≥ 18，且命令行里 `node server.js` 没有报错。

**Q：端口被占用？**
A：改 `config.js` 的 `port`，或在启动前设置环境变量 `PORT=3001`。

**Q：导入后单位数是 0？**
A：多半是第一行表头里没有「单位名称」列，或名称列为空。请先下载模板再填。

**Q：想让同事一起用？**
A：把「内网 IP + 端口」发给他们，例如 `http://192.168.1.20:3000`（`ipconfig` 可查本机内网 IP）。
首次访问时 Windows 防火墙可能弹窗，选「允许」。

**Q：数据会不会丢？**
A：数据都在 `db.json`，复制走就是备份，重启服务不会丢。

## 八、技术说明

- 后端：Node.js 原生 `http` 模块，不依赖任何第三方框架
- 前端：原生 HTML/CSS/JavaScript，不需要构建
- 数据：单个 JSON 文件
- 导入：自研解析（CSV 直接解析；xlsx 用 zlib 解开 zip 后读取 sharedStrings 与 sheet1）
- 导出：自研极简 xlsx 生成模块
- 跨域：接口已支持 CORS，可在 `config.js` 限制白名单

代码可自由使用、修改和二次开发。
